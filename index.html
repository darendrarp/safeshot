How the hybrid AI works

  1. On-device first. On Chrome desktop (v139+) with Gemini Nano downloaded, your text or screenshot is scanned locally via Firebase AI Logic (InferenceMode.PREFER_ON_DEVICE). Free, private, offline.
  2. Cloud fallback. If no local model is available, the same prompt runs on the cloud Gemini model — unless Private mode (ONLY_ON_DEVICE) is on, in which case the scan fails safe instead of sending your data anywhere.
  3. Verified output. Every AI finding is validated: for text, the flagged value must appear verbatim in your input; findings are merged with a deterministic pattern detector (API keys, JWTs, cards with Luhn check…). Hallucinations are dropped.
  4. You stay in control. Each result is labeled with its inference source (response.inferenceSource), so you always know whether your data stayed on-device or went to the cloud.

Built with Firebase AI Logic (hybrid inference), App Check, Anonymous Auth, Firestore and Remote Config. Requires Chrome on Desktop v139+ with the chrome://flags/#prompt-api-for-gemini-nano-multimodal-input flag for on-device inference.
